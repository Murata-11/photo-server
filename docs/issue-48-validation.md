# Issue #48：元画像プレビューからの保存とPCモック

2026-11-12（日本時間）。PR #49の修正版。POから共有画面に保存項目が出ないとの報告、元画像プレビュー方式とPCサイズのモック追加の指示を受けた。仕様・対象範囲は[製品仕様](product.md#詳細の元画像表示ダウンロードpcモックissue-48)、UIはiPhone 16とPCのPlayground、HTTP契約はOpenAPI `originalPhoto`を参照する。

## 変更と確認した動作

- Fileを渡すWeb Share API方式を元画像の直接プレビューに置き換えた。保存メニューのリンクから同じオリジンの元画像を新しいタブで開く。プレビューリンクにはdownload属性を付けず、通常のダウンロードも残す。
- `disposition=inline`はブラウザ内表示、`attachment`と省略時は従来のダウンロード。JPEG/PNG/WebPで元バイト列・Content-Type・名前・認証・private/no-store・nosniffを維持。不正値は400。両利用者による取得、未認証と未許可利用者の拒否、ゴミ箱内の元画像取得も確認した。
- 1440×960のPCモックを追加。1600pxと393pxのレビュー画面からPCレイアウトの寸法維持・縮小・操作・横はみ出しなしを確認。既存iPhoneモックは393×852を維持。実装はどちらも通常アプリと共用。
