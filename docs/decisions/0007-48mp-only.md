# ADR 0007：HEICを撤去し48MP対応だけを維持する

- 状態：承認済み。2026-11-11のPO「heifの対応不要だった。48MPの対応だけでいい。直して欲しい」に基づく。
- 対象：Issue #35。ADR 0006のHEIC/HEIF・カスタムネイティブ構成を置き換える。

アップロードはJPEG/PNG/WebPの静止画像に限定する。48MPの実寸8064×6048を受け付ける60MP上限と、50MiB上限を維持する。HEIC/HEIFはフロントとAPIの両方で未対応として拒否する。

sharp 0.35.5の標準配布バイナリに戻し、カスタムlibvips/libheif/libde265、検査プログラム、HEIF_INSPECTOR、構築用node-gyp/node-addon-api、HEIC素材と専用テスト設定を除去する。通常配布のsharpに含まれる内部依存を独自に組み替えることはしない。標準バイナリが他形式のローダーを持っていても、製品の受付形式を広げない。

48MP処理の資源制御として、終了可能な子プロセス・1件処理/2件待機・30秒上限は維持する。CIは重いネイティブ構築を廃止し、標準DockerでJPEG/PNG/WebPと拒否動作を検証する。PC/スマートフォンは通常の実API E2Eへ統合する。

DB・写真ファイルは変更しない。保存済みHEICも元画像のバイト配信と生成済みJPEGでの閲覧はできる。既存データの削除・自動変換・再デコードは行わない。本番更新・マージは別承認。
